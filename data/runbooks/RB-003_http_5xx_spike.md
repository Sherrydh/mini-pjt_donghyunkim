# RB-003 HTTP 5xx 에러율 급증

- 적용 서비스: order-api, payment-api, auth-api, search-api
- 심각도 기준: 5xx 비율 2% 이상 5분 지속 SEV3, 5% 이상 SEV2, 결제·로그인 불가 SEV1
- 최종 수정: 2026-10-01 / 작성: SRE팀

## 증상
- 알람 `Http5xxRateHigh`
- 게이트웨이 대시보드에서 특정 서비스의 502/503/504 증가

## 1차 확인 (원인 분류)
1. **상태 코드 구분**
   - 502: 업스트림 파드 비정상 종료·재시작 (OOM 의심 → RB-004)
   - 503: 가용 파드 없음, 서킷브레이커 open
   - 504: 업스트림 타임아웃 (DB 지연 → RB-001, 외부 API 지연)
   - 500: 애플리케이션 예외 → `query_logs` 로 ERROR 스택트레이스 확인
2. 최근 30분 내 배포 여부 확인 → 배포 직후 발생이면 RB-007 롤백을 1순위로 검토
3. 의존 서비스(auth-api 등) 동시 장애 여부 확인

## 조치
1. 배포 기인: RB-007 절차로 직전 버전 롤백
2. 의존 서비스 기인: 해당 서비스 온콜에 공유, 자체 서비스는 서킷브레이커/폴백 확인
3. 트래픽 기인: 레이트리밋 상향 또는 스케일아웃 (온콜 승인)

## 커뮤니케이션
- SEV2 이상은 장애 채널(#incident) 개설, 15분 주기로 상황 공유
