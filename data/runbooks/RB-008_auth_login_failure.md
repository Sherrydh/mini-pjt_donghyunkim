# RB-008 로그인 실패 급증 (auth-api)

- 적용 서비스: auth-api
- 심각도 기준: 로그인 성공률 95% 미만 SEV2, 80% 미만 SEV1
- 최종 수정: 2026-08-01 / 작성: 인증플랫폼팀

## 증상
- 알람 `LoginSuccessRateLow`
- 로그 `401 invalid_token`, `JWKS fetch failed`, `Redis timeout`

## 1차 확인
1. 성공률 하락이 전체 사용자인지 특정 클라이언트(앱 버전)인지 구분
2. 세션 저장소(Redis) 지연 확인: `get_metrics` 의 `redis_latency_ms`
3. 토큰 서명키(JWKS) 로테이션 일정 확인 — 로테이션 직후라면 캐시 갱신 문제 의심
4. 특정 IP 대역의 대량 실패 → 크리덴셜 스터핑(공격) 의심 → 보안관제 공유

## 조치
1. Redis 기인: Redis 온콜 호출, 읽기 레플리카 상태 확인
2. JWKS 캐시 문제: auth-api 롤링 재시작(온콜 승인) 으로 캐시 갱신
3. 공격 의심: WAF 차단 정책은 보안관제팀이 적용

## 금지 사항
- 장애 대응 중이라도 사용자 비밀번호·토큰 원문을 로그·채팅에 노출 금지
- 특정 사용자 계정 정보 조회는 고객지원 티켓 기반으로만 수행
