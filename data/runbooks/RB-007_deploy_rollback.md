# RB-007 배포 롤백 절차

- 적용 서비스: 전 서비스 (ArgoCD 배포)
- 최종 수정: 2026-10-05 / 작성: 플랫폼운영팀

## 롤백 판단 기준
- 배포 후 30분 이내 다음 중 하나 발생 시 롤백을 1순위로 검토
  - 5xx 비율 2% 이상, p99 지연 2배 이상, 파드 재시작 급증, 핵심 기능(로그인/결제) 실패
- 원인 분석보다 **복구가 우선**. 원인 분석은 롤백 후 진행

## 절차
1. #incident 채널에 롤백 시작 공지 (서비스명, 현재 버전, 대상 버전)
2. ArgoCD에서 해당 Application → History → 직전 정상 리비전 선택 → Rollback
   - CLI: `argocd app rollback <app-name> <revision-id>`
3. 롤백 후 10분간 5xx 비율, p99, 재시작 수 모니터링
4. DB 마이그레이션이 포함된 배포는 **애플리케이션만 롤백 불가할 수 있음** → 개발 리드 확인 필수

## 승인
- 업무시간: 서비스 온콜 판단으로 즉시 롤백 가능
- 배포 프리즈 기간(매월 말일 전후 3일)에는 롤백도 SRE 리드 공유 필수

## 사후 처리
- 24시간 내 포스트모템 초안 작성 (템플릿: postmortems/ 참고)
